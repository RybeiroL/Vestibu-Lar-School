# 📱 Vestibu-Lar School

## 🎯 Objetivo  
O **Vestibu-Lar School** é um aplicativo mobile criado para auxiliar estudantes do ensino médio na preparação para vestibulares.  
A aplicação oferece conteúdos direcionados das matérias que foram retiradas do currículo pelo novo ensino médio, além de contar com **inteligência artificial integrada** para sanar dúvidas e recomendar conteúdos com maior probabilidade de aparecer em provas.

---

## 👥 Público-Alvo  
Estudantes do ensino médio (principalmente os concluintes) que desejam ingressar no ensino superior, mas não possuem recursos para cursinhos preparatórios.

---

## 📚 Funcionalidades  
- Cadastro/Login (via e-mail/senha ou Google)  
- Dashboard com matérias como História, Geografia, Matemática, Português, Filosofia etc.  
- Conteúdos em formatos como textos explicativos, questões, simulados, curiosidades e dicas  
- **IA integrada** para responder dúvidas didáticas  
- Salvamento do progresso e preferências do usuário
